# Chivalry 2 C++ & Blueprint Reference

Generated reference documentation for **Torn Banner's `TBL` C++ classes and
selected Blueprints**, extracted from Chivalry 2. It's the companion reference to
the [ArgonSDK Field Guide](https://knutschbert.github.io/ArgonSDK-FieldGuide/) —
the guide explains *how* to mod; this reference is the raw API surface.

> [!tip] Search is the fastest way in
> Use the **search bar at the top** (or press `/`). Every class, struct, enum,
> function and Blueprint node on this site is indexed. Searching matches whole
> words, so try the bare symbol name (e.g. `TBLPlayerController`, `SpawnTBLAI`).

## What's here

- **C++ Classes & Structs** — ~1,470 pages under **SDK → Source → Classes**:
  function signatures, properties and their access levels. (Unreal prefixes: `A`
  actors, `U` objects, `F` structs, `E` enums, `I` interfaces.)
- **Namespaces & Enums** — see the [Namespaces index](SDK/Source/index_namespaces.md).
- **Blueprint nodes** — ~330 classes under **TBL_src_clean**, each with its
  Blueprint `nodes/` and node-graph images.

## What it provides

- Class function names and arguments
- Class properties and their access levels
- Blueprint node previews, where available
